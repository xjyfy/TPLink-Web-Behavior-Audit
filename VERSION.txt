SyslogAudit v3.1
Release: 2026-11-05

# 相对 v3.0 的增量改进（v3.1）

## 1. syslog 接收吞吐修复（核心）
- 现象：路由器上报量正常时，本机入库量仅为上游的约 12%（同一 30 分钟窗口：虚拟机独立接收 88,227 条 vs 本机 88,098 条前、本机实际仅约 1/7）。
- 根因：单线程「收包 + 解析 + 逐条写库」，UDP 内核接收缓冲不足，高并发时在内核层丢包。
- 修复：syslogd 改为接收/处理分离——接收线程只负责收包并入队（队列上限 50,000），独立处理线程每 150 条攒批 `insert_many` 写库；`SO_RCVBUF` 提升至 8MB（实测生效 8,388,608 字节）。
- 效果：同样 30 分钟窗口留存率提升到 **99.85%**；11:20~11:50 复测 96,532 条 → 96,504 条（**99.97%**，差 28 条），逐分钟无断层。

## 2. 监听地址与网卡指标
- syslog UDP 监听 `0.0.0.0:514`（默认监听所有网卡，开箱即用）；如需只监听某块网卡，修改 `config.py` 的 `SYSLOG_UDP_HOST` 为该网卡 IP 即可。
- 总览"网卡速率"排除 tailscale / virtualbox / vmware / loopback 等虚拟网卡，按物理网卡（lan1 1000Mbps）取值，修复被 Tailscale 4294Mbps 覆盖的问题。

## 3. 域名解析服务（domain_resolver.py，新增文件）
- 域名/IP ↔ 网站名 + 地理标签解析，结果写入 24 小时缓存表，每小时清理过期条目并回写基础表，避免重复查询。

## 4. 终端管理
- "最后在线"改由日志入库路径维护：每批入库时累积各 IP 的最大时间戳，批量 `UPDATE hosts SET last_seen=? WHERE ip=? AND (last_seen IS NULL OR last_seen < ?)`（只前进）；不再依赖该设备上报 DHCP 日志（导入/固定 IP 设备此前永远为空）。
- 新增 `idx_hosts_ip` 索引；`upsert_host()` 不再写 `last_seen`。
- 新增"长期离线"筛选：1 个月 / 3 个月 / 6 个月以上未在线（按 `last_seen` 判断，从未在线的设备也计入），筛选时按离线最久优先排序。

## 5. 导出与清理
- "不保存上网行为日志"补充说明：上网行为日志与系统日志中的行为管控（behavior_ctl）日志高度重复（实测几乎逐条成对），关闭保存可减少约一半入库量、提升采集与查询性能，并避免同一行为被重复统计。

## 6. 数据清理与写入稳定性
- `prune` 修复：原 `DELETE FROM logs WHERE ts < ? LIMIT 20000` 标准 SQLite 不支持（未编译 `SQLITE_ENABLE_UPDATE_DELETE_LIMIT`），每小时报语法错误、从未真正删除数据；改为 `DELETE ... WHERE rowid IN (SELECT rowid ... ORDER BY ts LIMIT ?)` 分批删除，批间释放写锁并休眠 50ms，单轮上限 20 万行，未删完由下一轮继续。
- 数据库写锁优化：连接 `timeout=30` / `busy_timeout=30000` / `synchronous=NORMAL` / `wal_autocheckpoint=4000`（连接级）；`journal_mode=WAL` 仅在初始化时设置一次（避免每连接重复设置额外抢锁）。
- `backfill_hourly()` 由单个 `BEGIN IMMEDIATE` 大事务拆成 9 条独立短事务，消除启动期长事务独占写锁导致的 `database is locked` 与入库批丢失。
- 验证：重启后启动块无 locked / syntax / Traceback / worker 异常，入库约 2,100 条/分钟无断层。

# 相对 v2.2 的增量改进（v3.0，均已包含）
- 应用类别统计表：自动维护所有应用类别统计，日志采集收到新类别自动累加；日志查询的应用类别输入框改为多选下拉框（默认全部、最多选 5 种、类别过多时横向双列+滚动条展示，数据与统计表联动）。
- 用户管理：新增用户管理页（仅系统管理员可见）；初始系统管理员 id=1 不可删除、不可改角色；系统管理员可新增/修改/删除其他管理员；分两种角色：
  * 管理员：拥有网站全部功能；
  * 审计管理员：仅可查看所有页面、导出 CSV、修改自己密码；禁止清空已导出日志、修改终端备注、导入历史 CSV、修改系统设置、重启服务，以及用户管理、设备启停、终端删除与导入、应用图标上传等写操作。
- 设备禁用/启用：数据来源设备列表新增禁用启用按钮；被禁用设备上报的 syslog 在接收入口直接丢弃（不入库、不写分流文件），Web 切换后约 2 秒内生效。
- 终端在线着色：总览终端IP/娱乐应用图及完整列表的 IP，按最近 1 小时有访问记录判定在线（绿色）/离线（灰色）。
- 终端IP完整列表：点击 IP 展开该终端使用最多的 Top10 应用与 Top10 网站。
- 日志查询导出：查询结果可一键导出为 CSV。
- 终端管理 CSV 导入导出：以 MAC 为主键自动覆盖，导入兼容 ":"/"-" 分隔并自动转为 "-" 大写格式；新增按备注名/IP/MAC 搜索、删除功能（DHCP 日志重现自动重新添加）。
- 版本号展示：后台左上角显示当前版本（v3.0）。

# 相对 v2 的增量改进（v2.1，均已包含）
- 明确并落实服务"脱离豆包等宿主进程独立运行"机制：
  * 服务（watchdog.py → app.py）必须以系统/调度方式启动，父进程是系统服务（如 WmiPrvSE）或 Task Scheduler，绝不能由豆包等应用进程派生（否则宿主退出会连带终止服务）。
  * 开机自启走 SYSTEM 计划任务（_run_hidden.vbs → watchdog.py），与豆包无关。
- 新增 watchdog.py：app.py 退出后 5 秒自动重启，输出写入 data/service.log（自愈 + 崩溃留痕），已实测杀掉 app.py 后自动拉起。
- install_service.bat / restart.bat / stop.bat 全部改为经由 watchdog.py 管理服务。

# v2 原有修复（均已包含）

- install.bat：本地离线包装不上时自动回退清华 PyPI 镜像。
- install.bat：IP 检测取带默认网关的实体网卡，排除虚拟网卡。
